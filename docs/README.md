## Konventionen

- Dokumente sind in Markdown geschrieben.
- Rechtschreibung nach Schweizer Standard, also immer "ss" und kein Eszett.
- Anführungszeichen immer als gerade Zeichen ("), nie als Guillemets.
- Jede Anforderung hat eine eindeutige ID (z. B. US-14, FR-27, NFR-05). Die Schreibweise steht in [L2, Kapitel 4.2](L2-anforderungsdokument.md#42-abkürzungen-und-ids).
- Commits, Issues und Tests verweisen auf diese IDs.
